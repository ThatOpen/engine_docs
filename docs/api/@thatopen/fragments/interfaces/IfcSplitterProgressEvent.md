# IfcSplitterProgressEvent

Payload of [IfcSplitter.onProgress](../classes/IfcSplitter.md#onprogress), fired when a stage finishes.

## Properties

### stage

> **stage**: [`IfcSplitterStage`](../type-aliases/IfcSplitterStage.md)

The stage that just finished.

***

### timeElapsed

> **timeElapsed**: `number`

How long the stage took, in milliseconds.
