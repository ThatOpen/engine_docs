DeferredPipelineDeferredPipeline — the rebuilt deferred postproduction pipeline.

Re-authored from scratch and validated pass-by-pass in the PipelineBisect harness (stages 18–23) before replacing the previous implementation. It reuses the SAME proven pass classes (capture / Hi-Z / AO / denoise / composite / FXAA); only the orchestration is new. Per frame:

  1. single-pass capture -> G-buffer (colour + depth + octa-normal + faceId)
  2. Hi-Z min-mip build from the captured depth
  3. AO estimator (screen-space Alchemy over Hi-Z, or world-space probe), half-res
  4. AO denoise (separable cross-bilateral)
  5. combined composite (AO . contour . sheen . tonemap . sRGB) -> LDR target
  6. FXAA -> the finished frame
  7. occlusion seam — direct (points into the frame) or layer (premultiplied splats)
  8. depth-occluded overlay (the floor grid) + flat overlay (hover/selection)
  9. tail (selection outline) / screen-copy

reuseCapture skips 1–4 and re-composites the cached G-buffer (overlay-only repaint). It allows to efficiently retrieve and remove meshes for specific model items. 📘 API. | | NearPlaneLineMaterial | A fat line material (screen-space quad expansion, real linewidth in px) that is also SAFE across the camera near plane.

three's stock LineMaterial expands each segment into a screen-space quad in the vertex shader. When a segment endpoint is behind the camera plane its projected w <= 0, so the NDC math is garbage and the quad blows up to span the whole screen — the "infinity streak" seen under clipping (and on LOD wires). Stock LineMaterial handles only the case where ONE endpoint is behind (it trims that endpoint to the near plane via trimSegment); it does nothing when BOTH endpoints are behind, which is the remaining streak.

This subclass injects the missing both-behind guard: if both endpoints are behind the camera plane the segment has no valid projection, so we collapse it offscreen (gl_Position past the far plane) instead of expanding a bogus quad. This mirrors the near-plane guard of fragments' LOD line shader: one guard, shared semantics across the fat-line consumers (section edges, measurement lines, LOD wires).

The guard lives in the material's OWN vertexShader string (NOT an onBeforeCompile patch), so it SURVIVES .clone() — ShaderMaterial.clone copies vertexShader, whereas it drops onBeforeCompile. That matters because ClipEdges clones the style material per model in local-clipping mode. | | Outliner | This component allows adding colored outlines with thickness to fragments in a 3D scene. Supports multiple named outline groups so different selections can be outlined with different colors / thicknesses at the same time. 📕 Tutorial. 📘 API. | | PointCloudLoader | Loads and streams out-of-core point clouds (Potree 2.0 octrees) and draws them THROUGH the world's deferred PostproductionRenderer: points stream by LOD and are drawn into the deferred occlusion seam, so they are correctly occluded by BIM geometry with no shader patching. Georeferenced precision (float64 anchor) and the tuned point material (adaptive sizing, overlap, max-size clamp, EDL) are handled internally — the app just points it at an octree.

potree-core is an OPTIONAL PEER DEPENDENCY — it is loaded lazily inside load, so apps that never load point clouds don't need it installed. | | PostproductionRenderer | A class that extends RendererWith2D and adds post-processing capabilities. 📕 Tutorial. 📘 API. | | RendererWith2D | A basic renderer capable of rendering 3D and 2D objects (Objec3Ds and CSS2DObjects respectively). | | SplatLoader | Streams 3D Gaussian splats THROUGH the world's deferred PostproductionRenderer as a first-class citizen of the pipeline.

The splats are drawn by the in-house WebGL2 GSplat renderer (EWA covariance billboards, a worker-driven global depth sort, a 10³ cell grid for distance LOD + frustum culling). They are rendered into the deferred occlusion seam in LAYER mode (premultiplied over the finished frame); critically, every splat writes its CENTRE's reversed-Z depth and the material depth- TESTS (GreaterEqualDepth, no depth write) against the BIM depth borrowed by the seam — so BIM geometry occludes the splats with NO shader patching, exactly as a real mesh would.

This replaces the previous Spark + 3d-tiles-renderer implementation; those optional peer dependencies are no longer needed. | | VolumeMeasurement | A basic dimension tool to measure volumes and display a 3D symbol with the numeric value. 📕 Tutorial. 📘 API. |

PointCloudRequestManagerThe byte-fetching contract potree-core drives. App-supplied so the transport
(local server, S3 Range, signed-URL re-mint) is fully pluggable.
PointCloudSettingsQuality / performance knobs for point rendering. Live-settable; the loader
reads them per frame, so changes take effect on the next frame with no reload.
PointCloudSourceA pluggable source for a point-cloud octree. The app supplies the URL and,
optionally, a request manager (e.g. a Range / signed-url adapter). Loaders stay
EXTERNAL to the loader: the component draws, the app decides how bytes are
fetched (local server, S3 Range, signed URLs…).
SplatRequestManagerThe byte-fetching contract, app-supplied so the transport is fully pluggable.
SplatSourceA 3D Gaussian splat source. Either:
  • a URL to a .ply / .compressed.ply file (INRIA 3DGS or its compressed variant), or its raw bytes, or
  • several LOD levels (lodUrls, finest → coarsest) concatenated into one global-sort buffer.

The bytes are decoded on the CPU (covariance precompute + Y-up flip) and uploaded to GPU textures by the in-house WebGL2 renderer (GSplat) — no external splat engine. |
